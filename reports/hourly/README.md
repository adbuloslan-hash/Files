# Hourly Reports

Hourly public-source updates are organized by:

`YYYY/MM/DD/YYYY-MM-DD-HH00-ET.md`

Each update should contain:
1. timestamp and coverage window
2. executive change summary
3. U.S. government/Federal Reserve
4. U.S. military posture
5. grid/data-center strategic developments
6. SATCOM public developments
7. historical/fascism evidence ledger
8. China / Israel
9. Japan / Taiwan / Australia
10. source ledger and confidence notes

If no material change is found in a category, the report should say so explicitly.
