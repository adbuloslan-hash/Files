# Deep Public-Source Audit Framework

## Evidence tiers
**Tier 1:** primary official records, statutes, archives, budgets, hearings, inspector-general reports.

**Tier 2:** major institutional research and peer-reviewed work.

**Tier 3:** reputable investigative reporting with identifiable sourcing and documentary support.

**Tier 4:** claims requiring corroboration.

Anonymous or unsupported social-media claims are leads, not established evidence.

## Hourly model
Each hourly run should identify meaningful changes in official releases, posture announcements, legislation, budgets, exercises, satellite-program announcements, infrastructure planning and well-corroborated reporting.

If no meaningful change is identified, say so.

## Conceptual topology
Use:
governance -> organizations -> publicly acknowledged assets -> alliances/dependencies -> communications categories -> logistics/industrial base -> legal/budget authority -> current developments.

Every consequential assertion should carry provenance and an appropriate confidence level.

## Boundary
OSINT only. No unauthorized network access, probing, exploit mapping, protected coordinates, targeting-quality orbital data, classified material or CUI.
